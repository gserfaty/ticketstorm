# Contributing

Thanks for your interest in TicketStorm.

- `main` is protected. Contributions go through a pull request; direct pushes are not accepted.
- Every pull request needs an approving review from the code owner (@gserfaty, see `.github/CODEOWNERS`) before it can merge.
- Fork the repo, create a branch, and open a pull request against `main`.
- Before opening it, run `npm run typecheck && npm test && npm run build` and add an entry under the top section of `CHANGELOG.md`.

Setup instructions are in [README.md](README.md).
